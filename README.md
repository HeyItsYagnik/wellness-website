# TerraElix Website

This folder contains the complete TerraElix React + Vite website source code.

## Run in VS Code

1. Install Node.js 20 or newer.
2. Open this `terraelix` folder in VS Code.
3. Open the VS Code terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Main files

- `src/App.tsx` — website content and interactions
- `src/index.css` — styling, colors, fonts, responsive layout, and animations
- `package.json` — project dependencies and commands
- `vite.config.ts` — Vite configuration

The website uses remote image URLs from the original design, so an internet connection is needed to display all product imagery.
